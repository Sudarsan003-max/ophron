# MEGA PROMPT: OPHRON WEBSITE — COMPLETE WEBSITE COPY EXTRACTION & PREMIUM WORD DOCUMENT

## 1. ROLE & OBJECTIVE

Act as a Senior Website Content Auditor, Web Content Extraction Specialist, Corporate Document Designer, and Brand Identity Consultant.

Your task is to inspect the complete existing OPHRON company website and create a **professional Microsoft Word (.docx) document containing the entire website's actual text and copy, in the same order and structure as it appears on the website.**

This document is intended exclusively for website-copy reference, review, editing, content approval, and maintenance.

**The deliverable is a faithful website-copy document, not a newly written company profile, marketing proposal, business report, or redesigned website.**

## 2. ABSOLUTE CONTENT RULES

Follow these requirements without exception:

1. Extract only text and content that are actually present on the existing OPHRON website.
2. Do not write new marketing copy, introductions, explanations, descriptions, recommendations, or conclusions.
3. Do not rewrite, paraphrase, improve, shorten, expand, correct, or change the wording of the original website copy.
4. Preserve the exact wording, spelling, capitalization, punctuation, numbers, symbols, headings, subheadings, calls to action, and labels.
5. Do not invent company information, services, statistics, certifications, client names, testimonials, addresses, contact information, or business claims.
6. Do not add content from search engines, other websites, social media, external company profiles, or your own knowledge.
7. Do not add an executive summary, company overview, project analysis, recommendations, or any other original content.
8. Do not silently omit repeated text, small labels, button text, navigation links, footer content, or content appearing inside expandable sections.
9. Preserve duplicated wording when it appears in multiple locations on the website.
10. Do not include technical code, HTML, CSS, JavaScript, developer comments, API responses, database records, or implementation notes as website copy.
11. Do not include descriptions of images unless the website itself visibly displays that text.
12. If any content cannot be accessed or verified, record it separately in a clearly identified extraction-issues section. Never fill gaps by guessing.

The document must contain the website's copy only, apart from minimal document-navigation elements such as a table of contents and page numbers.

Follow internal navigation links and inspect every accessible, relevant company-owned page within the website's scope.

Avoid external websites unless they are explicitly part of the requested website scope.

## 4. PRESERVE THE ORIGINAL WEBSITE STRUCTURE

The Word document must follow the same order as the original website.

For each page, preserve the hierarchy:

Website page
→ Section
→ Heading
→ Subheading
→ Paragraph
→ Bullet points
→ Buttons and calls to action
→ Supporting labels

Keep the original relationship between headings, paragraphs, lists, buttons, and their associated sections.

For a multi-page website, organize content by page in a logical navigation order. Preserve the original order within every page.

Use the original page title as the corresponding document section heading wherever possible.

Do not merge unrelated sections, reorganize content for marketing purposes, or move text between pages.

Include the source page URL as a small reference beneath the page heading or in the document's page-reference information. URLs are metadata for traceability, not newly written website copy.
